# Hangarin

Hangarin is a Django-based Task and To-Do Manager designed to help users organize and manage their tasks, notes, and subtasks.

## Features

- Task management
- Create, edit, and delete tasks
- Task status tracking
- Task priorities
- Task categories
- Deadline management
- Notes management
- SubTask management
- Django Admin management
- Pagination
- Bootstrap user interface
- Faker-generated sample data

## Technologies

- Python
- Django
- SQLite
- Bootstrap
- HTML
- CSS
- django-widget-tweaks
- Faker
